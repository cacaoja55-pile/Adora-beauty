# Adora Beauty — site vitrine

Ouvrir `index.html` dans un navigateur pour tester le site.

Pages :
- index.html : accueil
- femmes.html : page féminine rose + galerie
- hommes.html : page masculine sombre + galerie
- services.html : services et tarifs
- contact.html : adresse + WhatsApp

À personnaliser avant mise en ligne :
1. Remplacer les photos de démonstration par les photos d'Adora Beauty/Nina, avec les droits d'utilisation.
2. Vérifier l'adresse exacte sur Google Maps.
3. Ajouter les horaires si vous souhaitez les afficher.
4. Ajouter un logo réel si vous en avez un.

Les boutons WhatsApp sont déjà configurés avec les deux numéros fournis.
